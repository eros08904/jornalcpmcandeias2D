PUBLICAR O JORNAL CPM NO GITHUB PAGES

1. Extraia todos os arquivos deste ZIP no seu computador.
2. No repositório do GitHub, envie os arquivos extraídos — não envie o ZIP.
3. Mantenha index.html, 404.html e a pasta assets juntos na raiz do repositório.
4. No GitHub, abra Settings > Pages.
5. Escolha Deploy from a branch, selecione a branch main e a pasta /(root).
6. Salve e aguarde o GitHub concluir a publicação.

Se o repositório já tiver um index.html, substitua-o pelo arquivo deste pacote.
